# ✦ _mr_einstein__ — Developer Portfolio

A retro-cyberpunk developer portfolio with an interactive NPC companion (Gojo), boot-up terminal animation, and a pixel-art aesthetic — all in a single-page vanilla build.

> *"Domain Expansion: Perfect Syntax."*

## 🚀 Live

Hosted via GitHub Pages — [**View Portfolio**](https://mr-einstein-x9.github.io/Portfolio/)

## ⚡ Highlights

- **Boot Screen** — OS-style loading sequence with animated progress bar
- **Interactive NPC** — Gojo walks the navbar, waves on entry, reacts to clicks with custom dialog, and triggers Domain Expansion (Infinity mode) if you click too many times
- **Custom Cursor** — Dot + ring cursor with hover expansion on interactive elements
- **Terminal Cards** — Hero and contact sections styled as live terminals with typewriter output
- **Animated Skills** — Progress bars with scroll-triggered fill + live counter
- **Current Project** — Spotlights what I'm actively building (Sanjaya) with animated border glow, shimmer title, and progress tracker
- **Responsive** — Works on mobile, tablet, and desktop

## 🛠️ Tech

| Layer | Stack |
|---|---|
| Structure | HTML5 (single page) |
| Styling | Vanilla CSS (custom properties, animations, glassmorphism) |
| Logic | Vanilla JavaScript (no frameworks, no dependencies) |
| Typography | Pixel Operator, Press Start 2P (Google Fonts) |
| Hosting | GitHub Pages |

**Zero dependencies. Zero build step. Just open `index.html`.**
